ЯЗЫК ПРИЛОЖЕНИЯ: полностью русский

────────────────────────────────────────────
УСТАНОВКА APK (готовый файл GalleryX_v1.0.0.apk)
────────────────────────────────────────────
1. Скопируйте APK на телефон.
2. Откройте файл — Android спросит разрешение
   «Устанавливать из этого источника» — разрешите.
3. Установите. Старых версий нет — это первая версия.
   (При будущих обновлениях удаляйте старую версию
   перед установкой новой.)

────────────────────────────────────────────
ПЕРВЫЙ ЗАПУСК
────────────────────────────────────────────
• Приложение сразу запросит доступ к фото и видео —
  разрешите (нужно для показа медиа).
• Затем «Доступ ко всем файлам» (All files access) —
  нужно для создания папок, перемещения, копирования,
  корзины и сейфа.
• Один раз выберите КОРНЕВУЮ ПАПКУ (например, в Download
  или DCIM) — все новые папки создаются внутри неё,
  так удобно копировать на ПК.
• Служебные папки (корзина и сейф) создаются ТОЛЬКО после
  выбора корневой папки и живут внутри неё в скрытом
  каталоге .GalleryX. В корне памяти телефона приложение
  ничего не создаёт. При смене корневой папки служебный
  каталог переезжает автоматически вместе с содержимым.
• Сама корневая папка в «Альбомах» не показывается —
  только папки внутри неё (любой вложенности).

────────────────────────────────────────────
РЕЖИМ МАСКИРОВКИ (главная фишка)
────────────────────────────────────────────
Настройки → Режим маскировки:
• Включите режим — галерея останется ОБЫЧНОЙ, но из неё
  исчезнут: корневая папка (все «Мои папки» и файлы в них),
  сейф, пункт «Корневая папка» и сам пункт «Режим
  маскировки» в настройках.
• Чтобы снова всё показать — удерживайте заголовок
  «Галерея» на главном экране 3 секунды. Во время
  удержания НИЧЕГО не отображается (ни индикатора,
  ни вибрации) — заголовок выглядит обычным текстом.
• PIN-код (только цифры) ОДИН на всё: он защищает сейф,
  заблокированные папки и запрашивается после 3-секундного
  удержания заголовка. Нет PIN — скрытое открывается сразу.
• Пункт «PIN-код для маскировки» (виден, когда PIN задан):
  включён — после удержания заголовка спрашивается PIN;
  выключен — скрытое открывается сразу, а PIN продолжает
  защищать сейф и заблокированные папки. Выключить пункт,
  отключить или сменить PIN можно только после ввода
  текущего PIN.
• Сейф без PIN не открывается: при первом входе приложение
  само предлагает создать код. Вход в сейф сразу открывает
  ввод PIN — без промежуточного экрана «Сейф защищён». То же при попытке отправить
  файлы в сейф без PIN. Сейф запирается автоматически при
  выходе — отдельной кнопки-замка больше нет.
• Кнопка «глаз» (скрыть вручную) есть только на главных
  вкладках: Галерея и Альбомы.
• Скрытие и ОТ ДРУГИХ ПРИЛОЖЕНИЙ: пока маскировка «закрыта»
  (глаз, таймер 1/5 мин, сворачивание), в корневой папке
  создаётся файл .nomedia и фото/видео корня пропадают из
  WhatsApp, Telegram, системного выбора файлов и т. д.
  После удержания заголовка 3 с флаг удаляется, файлы заново
  индексируются и снова доступны везде. Внутри приложения
  корневая папка при этом читается напрямую с диска — всё
  видно сразу, не дожидаясь индексации.
• Пока маскировка «закрыта», копирование и перемещение
  в папки устройства по-прежнему доступны — скрыты только
  сейф и всё, что связано с корневой папкой.
• Автоматическое скрытие (4 варианта):
    – При сворачивании приложения
    – Через 1 минуту
    – Через 5 минут
    – Только вручную (в шапке будет кнопка «глаз» —
      «Скрыть сейчас»). В этом режиме галерея остаётся
      открытой сколько угодно — хоть месяцы, хоть после
      перезапуска приложения — пока вы не нажмёте «глаз».
      Таймерные режимы тоже переживают перезапуск:
      досчитывают оставшееся время.

────────────────────────────────────────────
ВОЗМОЖНОСТИ
────────────────────────────────────────────
• Все фото и видео устройства, фильтры Все/Фото/Видео
• Папки: свои (в корневой) и папки устройства
• Вложенные папки любой глубины: внутри своей папки
  меню «⋮» → «Создать папку»; подпапки показываются
  карточками (как в «Альбомах») в начале сетки.
  В самих «Альбомах» — только папки первого уровня корня,
  их содержимое (включая подпапки) видно в общей галерее
• Копирование / перемещение файлов и альбомов в ЛЮБУЮ
  папку: лист назначений содержит «Новая папка…»
  (создаётся прямо в текущей папке), корневую, все свои
  папки, папки устройства и «Другая папка на устройстве…»
  (обзор всей памяти с созданием папки на месте)
• Создание папок, перемещение и копирование (с прогрессом
  и отменой), мультивыделение файлов
• Три вкладки внизу: Галерея, Альбомы, Настройки.
  Избранное — фильтр в Галерее: Все / Фото / Видео / Избранное
  (простой текстовый чип, без значка).
• ФОНОВЫЙ РЕЖИМ ОПЕРАЦИЙ: копирование, перемещение, удаление,
  отправка в сейф/корзину и восстановление идут под защитой
  foreground-сервиса с уведомлением о ходе («Копирование · 42%»).
  Свернули приложение, смахнули из «недавних», погас экран —
  операция всё равно доработает до конца, а итог придёт
  уведомлением «Готово: N из M». Копия пишется во временный
  скрытый файл и переименовывается только после полной записи,
  поэтому «половинок» файлов в галерее не бывает. На Android 13+
  один раз спрашивается разрешение на уведомления (отказ не
  мешает работе, просто не будет видно прогресса).
• Корзина: удалённое хранится 30 дней, восстановление.
  Корзина показывает ВСЁ удалённое всегда — и из корневой
  папки, и из других папок телефона, даже при активной
  («закрытой») маскировке.
  Файлы, положенные в <корень>/.GalleryX/trash вручную
  (файловым менеджером), тоже видны в корзине; срок 30 дней
  считается с момента, когда приложение их заметило. При
  восстановлении таких файлов (исходное место неизвестно)
  они попадают в папку <корень>/Restored — она создаётся сама и
  автоматически удаляется, когда становится пустой.
• Сейф: фото/видео прячутся в скрытую папку, вход по PIN
• Просмотрщик единый для фото и видео: листаются все
  элементы по порядку (фото и видео вперемешку, в «Видео» —
  все ролики подряд). Видео проигрывается ПРЯМО на странице
  и стартует само при перелистывании БЕЗ ЗВУКА; кнопка
  динамика в нижней панели включает/выключает звук (выбор
  действует на все видео, пока открыт просмотрщик). Во время
  воспроизведения можно листать дальше, тянуть вниз, ставить
  паузу (кнопка по центру или в панели), перематывать ползунком.
  Отдельного видеоплеера больше нет — плеер один
• Фото открываются в полном исходном качестве (декод до
  4096 px по большей стороне — предел видеопамяти экрана;
  меньшие снимки показываются 1:1 без потерь)
• Зум щипком (до 8×) и двойным тапом, свайп вниз — закрыть,
  свайп вверх — свойства файла
• Оформление просмотрщика (v3.11): чёрный фон и плавающие
  «стеклянные» капсулы. Сверху: круглая «назад», капсула
  «день недели / дата · время» (тап — свойства), круглая «⋮»
  (меню: Переместить, Копировать, В сейф, Заметка, Открыть
  в другом приложении, Установить как обои, Свойства, Удалить).
  Снизу: капсула плеера (для видео: play/pause, время,
  ползунок, звук) и капсула действий (Избранное · Поделиться ·
  Заметка · Удалить · Свойства; в корзине/сейфе — Поделиться ·
  Заметка · Восстановить · Удалить навсегда · Свойства).
  Панели выезжают/уезжают за край экрана, кнопки «пружинят»
  при нажатии. Фото открывается, «вырастая» из миниатюры,
  и при свайпе вниз / «назад» возвращается в неё.
• Свойства файла (v3.11): шапка с бейджем формата (JPG, MP4…),
  карточка «Файл» (разрешение · мегапиксели или длительность ·
  размер), карточка «Камера» из EXIF (модель, диафрагма,
  выдержка, ISO, фокусное), «Место съёмки» (координаты,
  кнопка «Карты»), строки «Тип», «Альбом», «Путь» (тап —
  скопировать). Если в EXIF есть дата съёмки, она показана
  вместо даты изменения файла.
• Альбомы: выделение нескольких папок, копирование /
  перемещение СОДЕРЖИМОГО альбома (только файлов, включая
  вложенные папки — плоским списком) в любую папку; сама
  папка никогда не копируется и остаётся на месте; удаление,
  переименование (при выборе одной своей папки), «выбрать все»
• Ячейки сетки (медиа и альбомы) всегда квадратные со
  скруглёнными углами при любом числе колонок; бейджи
  (длительность видео, «Мои папки», избранное, галочки)
  и подписи автоматически уменьшаются при 4–6 колонках
• Информация о файле, шеринг
• Поиск, 6 режимов сортировки, щипок для смены размера сетки
• Блокировка папок: долгое нажатие на альбом → «Заблокировать»
  (нужен PIN; без PIN приложение предложит его создать).
  На карточке появляется замок, обложка не показывается,
  а файлы из такой папки (включая вложенные) исчезают из
  Галереи, Избранного и Видео — независимо от маскировки.
  Открыть папку и снять блокировку можно только после PIN.
  Название заблокированной папки тоже прячется: «test» → «t**t»
• Заметки к файлам: в просмотрщике кнопка «заметка» (золотая,
  если заметка уже есть) открывает полноэкранный лист с
  заголовком и текстом любой длины. Если заметка уже есть —
  она открывается в режиме ПРОСМОТРА (без клавиатуры, текст
  можно прокручивать и выделять); если заметки нет — сразу
  в режиме РЕДАКТИРОВАНИЯ. Внизу одна кнопка-переключатель:
  в режиме правки — «Просмотр» (+ «Сохранить»), в просмотре —
  «Редактировать». Слева от заголовка — корзина (удалить
  заметку), она появляется, только когда заметка есть.
  Лист не закрывается свайпом (чтобы длинный текст
  прокручивался); закрыть — крестик вверху, набранное при
  этом сохраняется само.
  В сетке у файлов с заметкой — маленький значок.
  Заметки хранятся в базе SQLite в корневой папке:
  <корень>/.GalleryX/galleryx.db — она переезжает вместе
  с корнем и копируется на компьютер вместе со всеми папками
  (пока корень не выбран — во внутренней базе, при выборе
  корня записи переносятся). При переименовании/переносе
  файлов и папок, отправке в корзину/сейф и обратно заметки
  следуют за файлом.
• Новые фото и видео (камера, загрузки) появляются в сетке
  сами: приложение следит за MediaStore и обновляет список
  при возврате из другого приложения
• Размер сетки (медиа 2–5, альбомы 1–3; альбомы по умолчанию 3)
  применяется сразу, без перезапуска; настраивается в
  Настройках и щипком
• Автоскрытие маскировки по умолчанию — «только вручную»
  (кнопка-глаз); таймеры и скрытие при сворачивании включаются
  в настройках маскировки по желанию
• Приложение запоминает последнюю вкладку и открывает её
  при следующем запуске
• Доступ к файлам запрашивается при первом запуске. Если
  позже отозвать разрешение в настройках Android, приложение
  снова покажет экран запроса — без доступа оно не работает
  (отдельной строки в «О приложении» больше нет)
• Тёмная/светлая/системная тема
